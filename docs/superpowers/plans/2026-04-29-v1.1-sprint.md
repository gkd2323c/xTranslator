# xTranslator v1.1 Sprint Plan — 完整可用闭环

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐"编辑→翻译→输出可用文件"完整闭环的剩余缺口，接入 HTTP proxy、集成 TCSC UI、添加翻译进度条和 Finalize 流程，打包为可直接交付给翻译组的工具。

**Architecture:** 5 个独立任务，每个可单独验证。P0 任务（Proxy/TCSC）修改核心通信层；P1 任务（进度条/Finalize）增强 UI 体验；P2 任务（Strings 写入闭环）完成编辑→输出完整流程。

**Tech Stack:** Rust (xt-core + Tauri) + React + TypeScript + react-i18next

pub async fn tcsc_convert(

) -> Result<String, String> {
    let result = match direction.as_str() {
        "to_simplified" => tcsc::to_simplified(&text),
        "to_traditional" => tcsc::to_traditional(&text),
        _ => return Err("Invalid direction".into()),
    };

}

### 3.1: 添加 ProgressBar 组件

创建 `ui/src/components/ProgressBar.tsx`：

```typescript
import React from 'react';

interface ProgressBarProps {
  translated: number;
  total: number;
  className?: string;
}

export const ProgressBar: React.FC<ProgressBarProps> = ({ translated, total, className }) => {
  const percent = total > 0 ? Math.round((translated / total) * 100) : 0;
  return (
    <div className={`progress-bar-container ${className || ''}`}>
      <progress value={percent} max={100} />
      <span className="progress-label">{translated}/{total} ({percent}%)</span>
    </div>
  );
};
```

### 3.2: 在 appStore 中计算进度

在 `appStore.ts` 中添加计算属性：

```typescript
const translationProgress = useMemo(() => {
  const total = strings.length;
  const translated = strings.filter(s => s.translation && s.translation.trim() !== '').length;
  return { translated, total };
}, [strings]);
```
